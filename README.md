# فضاء أولياء دار الإحسان (Dar El Ihsan Parents Space)

البوابة الرقمية المستقلة لأولياء أمور أطفال دار الإحسان لمتابعة التطور التربوي والنفسي لأبنائهم من أي هاتف أو حاسوب.

---

## 🌟 الخصائص والميزات الأساسية
- تسجيل دخول آمن ودائم دون إعادة إدخال البيانات في كل مرة عبر رموز Supabase Auth التلقائية التجديد في localStorage.
- دعم الدخول باسم المستخدم، رقم هاتف الولي، رقم قيد التلميذ، أو رمز التسجيل السري.
- عرض بطاقة ملف الطفل، القسم، وتوجيهات الإدارة الخاصة بالولي.
- الاطلاع على استمارات التقييم البيداغوجي الرسمية المعتمدة مع كشف تفاصيل المهارات والنسب المئوية والدرجة صفر للمهارات غير المقيمة.
- تحميل استمارات التقييم والتقارير بصيغة PDF نقية ومباشرة بمقاس A4 القياسي.
- معاينة صورة البرنامج الأسبوعي للقسم وتكبيرها وتحميلها على الهاتف.
- استلام الإشعارات الفورية (Web Push) على شاشة الهاتف حتى والتطبيق مغلق، مع نغمة التنبيه الصوتية والاهتزاز.
- احترام تام لخصوصية شاشة القفل (عدم إظهار أسماء الأطفال أو التشخيصات الحساسة على شاشة القفل).
- قائمة جانبية منزلقة للهواتف الذكية (Slide-in Drawer) وإزالة التكرارات.
- تطبيق ويب تقدمي PWA قابل للتثبيت المباشر على شاشة الهاتف من متصفح Chrome أو Safari.

## 🚀 كيفية التشغيل والنشر السريع

### 1. النشر على GitHub Pages (مباشرة وبدون أي بناء مسبق)
المشروع مبني بأسلوب أصلي متين (Pure Native Architecture) بدون الحاجة إلى تثبيت تبعيات ثقيلة أو أوامر بناء:
1. أنشئ مستودعاً جديداً على GitHub باسم `DarElIhsan-Parents`.
2. ارفع جميع ملفات هذا المجلد إلى الفرع الرئيسي (`main`).
3. اذهب إلى **Settings** المستودع -> **Pages** -> اختر مصدر النشر:
   - **Source:** Deploy from a branch -> الفرع: `main` / المجلد: `/ (root)`.
   - أو عبر **GitHub Actions** باستخدام سير العمل المدمج `.github/workflows/deploy.yml`.
4. سيتم نشر الموقع فوراً على الرابط:
   `https://<username>.github.io/DarElIhsan-Parents/`

### 2. التشغيل المحلي (Local Development)
يمكنك تشغيل الموقع محلياً بأي خادم ويب خفيف، على سبيل المثال:
```bash
# باستخدام Python:
python3 -m http.server 8000

# أو باستخدام Node.js:
npx serve .
```
ثم افتح في المتصفح: `http://localhost:8000`

## 📱 تثبيت التطبيق على الهاتف (PWA)
التطبيق مجهز بالكامل للعمل كتطبيق هاتف ذكي مستقل (Progressive Web App):
- **على هواتف Android (متصفح Chrome):**
  1. افتح رابط الموقع في متصفح Chrome.
  2. اضغط على زر «تثبيت التطبيق» الظاهر في الواجهة، أو اضغط على قائمة المتصفح (⋮) واختر **«تثبيت التطبيق»** (Install app).
  3. ستظهر أيقونة التطبيق الرسمية على شاشتك الرئيسية، ويعمل التطبيق كنافذة مستقلة بدون شريط المتصفح.

- **على هواتف iPhone (متصفح Safari):**
  1. افتح الرابط في Safari.
  2. اضغط على زر المشاركة (Share) في أسفل الشاشة.
  3. اختر **«إضافة إلى الشاشة الرئيسية»** (Add to Home Screen) ثم اضغط **إضافة**.
